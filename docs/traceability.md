# Матриця трасування: правила → тест-кейси → автотести

> Task A, доповнюється в Task B. Скопіюйте у `docs/traceability.md`. Кожне правило
> специфікації — один рядок, навіть якщо тест-кейсів для нього ще немає (тоді це видно).
> Автотест записуйте як `файл › назва тесту`.
>
> Приклад курсивом — з **іншої** системи (онлайн-бібліотека громади).

## Підсумок

- Правил покрито тест-кейсами: <X> з 10
- Правил покрито автотестами: <Y> з 10
- Відкриті питання: <Q-…> — чим вони закінчилися в тестах (не автоматизовано / автоматизовано лише однозначну частину)
